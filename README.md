# Python Utilities & Learning Exercises

A collection of Python scripts covering various programming concepts, data processing, and system administration utilities.

## Description

This project contains multiple Python programs demonstrating core programming concepts and practical utilities:
- **Core Python Concepts**: Loops, conditionals, data types, collections
- **Algorithms**: Caesar cipher encryption, data analysis
- **System Administration**: System information gathering
- **Data Processing**: JSON file handling, CSV operations, data calculations

Perfect for learning Python fundamentals and exploring real-world applications.

## Project Structure

```
├── sys-admin.py                 # Gathers system information (uname, processes)
├── jsonFileHandler.py           # JSON file reading and writing operations
├── analyze-insulin.py           # Data analysis utilities
├── collections-lab.py           # Collections (lists, sets, dicts) operations
├── caesar-cipher.py             # Caesar cipher encryption/decryption
├── calc_weight_json.py          # Weight calculations from JSON data
├── categorize-values.py         # Value categorization utilities
├── conditionals.py              # If/else conditional examples
├── for-loop.py                  # For loop examples and exercises
├── hello-world.py               # Basic Python program
├── string-data-type.py          # String manipulation operations
├── string-insulin.py            # String processing for insulin data
├── while-loop.py                # While loop examples
├── net-change.py                # Network/data change calculations
├── numeric-data.py              # Numeric operations and calculations
├── insulin.json                 # Sample insulin data in JSON format
├── car_fleet.csv                # Sample car fleet data in CSV format
└── *-seq-clean.txt              # Cleaned sequence data files
```

## Usage

### System Administration
```bash
# Gather system information
python sys-admin.py
```
Outputs system details like:
- System name and kernel version
- IP configuration
- Active processes running

### Data Analysis
```bash

python analyze-insulin.py

# Categorize values from data
python categorize-values.py

# Calculate weight metrics
python calc_weight_json.py
```
